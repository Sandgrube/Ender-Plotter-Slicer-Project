# Examples

- `sample_line_art.svg` is a small vector input file for SVG import testing.
- `sample_raster.png` is a small raster input file for PNG import testing.
- `sample_project.plotproj.json` is a minimal project file using the built-in Neptune 2 profile.


## Pencil reference

`pencil_still_life.png` contains a shaded sphere and a soft cast shadow. Import it with a pencil preset to check highlights, midtones and shadow density. Rebuild it and the comparison with `python tools/render_pencil_demo.py`.
